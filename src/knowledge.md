# MulleUI Project Knowledge

## Project Structure

This project appears to be part of the MulleUI framework, which provides window management and UI functionality.

## Important Guidelines

### Reflect Directory

- **DO NOT EDIT** files in the `reflect/` directory directly
- Files in this directory (like `_MulleUIPureWindow-export.h`) are automatically generated by `mulle-sde`
- These files will be recreated/regenerated frequently, so any manual changes will be lost
- If changes are needed to these files, they should be made through the proper mulle-sde mechanisms

### Naming Conventions

- The project uses a prefix-based naming convention (e.g., `UIPureWindow`, `MulleUI`)
- Categories are named with a pattern like `ClassName+CategoryName.h/m`

## File Organization

- Core window functionality is in `UIPureWindow.h/m`
- Additional functionality is organized into categories (e.g., `UIPureWindow+UIEvent.h/m`)
